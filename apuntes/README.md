# Apuntes
## Formato basico documento
```
<!DOCTYPE html>
<html>
    <head>
    </head>
    <body>
    </body>
</html>
```
## Etiquetas basicas HTML
### Especificar tipo de documento
`<!DOCTYPE html>`
### Titulo
`<title>La meva primera web</title>`
### Encabezado
`<h1>Hola món</h1>`
### Parrafo
`<p>Aquesta es la meva primera pagina web</p>`
### Importancia especial
`<strong>pagina web</strong>`
Es preferible usar estilos para evitar problemas de accesibilidad con el lector de pantalla
### Emfasis
`<em>meva primera</em>`
Es preferible usar estilos para evitar problemas de accesibilidad con el lector de pantalla
### Listas
`<ul> ... </ul>`
`<ol> ... </ol>`
`<li> ... </li>`
